# AI Passport 固件

首版设备客户端位于 `firmware/`，面向 AI Passport 的 ESP32-C3、8 MiB Flash、
240×320 圆角屏、三个 ADC 按键与 ES8311 音频通路。复用了 voice-memo 的板级支持、
中文字体、设置、Wi-Fi 与 BLUFI 生命周期、即时短按判定及熄屏策略。
现有 memo 项目仍作为硬件参考。

## 页面与操作

| 页面 | 短按 | 长按 |
| --- | --- | --- |
| 会话列表 | 上下选择，越过页边界后加载另外四条会话。OK 进入选中会话。 | OK 新建会话并持续录音，上键循环切换一级页面，下键休眠。 |
| 对话 | 上下键滚动完整的本地消息，到边界后切换提问／回复或加载相邻历史对话。OK 直接发送已审阅草稿，或重试失败、未确认的回复。 | OK 开始新消息录音，或重录待发送内容。下键返回会话列表。 |
| 录音 | 松开 OK 完成转写，在对话中显示待发送文字。 | 持续按住 OK 录音。下键在保存开始前取消本次录音并返回会话列表，正在保存时返回列表并继续保存。 |
| 设置 | 上下选择，OK 进入编辑或保存。数值编辑时上键增加、下键减少。 | 在设置列表中，上键循环切换一级页面，下键休眠。在属性编辑中，下键取消未保存的修改并返回设置。 |
| 配网 | OK 结束配网并恢复正常联网。 | 下键结束配网并返回设置。 |

对话页直接显示待发送文字供检查，短按 OK 发送显示的草稿版本，长按 OK 重录。

在“正在录音”或“正在完成转写”期间取消会保留此前文字。进入“正在保存”后，
长按下返回列表，保存继续进行。重录失败时保留此前文字。
已有多段草稿合并为完整输入进行审阅。会话列表与设置登记在同一份
一级页面列表中，长按上键依次切换并循环，新增一级页面沿用同一注册方式。一级页面
长按下键休眠，详情中长按下键逐层退出。手动休眠先暂停联网，并等待按键松开。
重新发现服务器可在设置的服务器选项中按 OK。每次短按独立响应，按键驱动的
多击事件不触发额外动作。

设置包括网络、服务器、音量、亮度、熄屏时间、深度休眠时间、主题、时区与版本。深度休眠从熄屏后
开始计时。选中会话标题横向滚动，日期和未选中项采用有边界的单行布局。页面拥有自己
的控件和动画，切页时先载入固定过渡屏，再删除离开的页面。

会话列表来自 Go 管理的索引，初始名称为“新会话”。首段录音转写成功后，客户端
直接取转写开头作为标题，并请求 Go 更新 Hermes。内部 ID 保存在协议字段中。

## 紧凑布局后的三轮顺序审查

三轮由三个新的独立 agent 顺序审查完整项目，每轮均在上一轮审查、修复与聚焦
验证结束后启动。

1. 第 1 轮确认两项 P2 边界问题。五分钟录音与连接／转写收尾共用截止时间，且
   已满 64 段的草稿无法再创建重录段。完整请求现增加有界的一分钟预算，音频
   时长及字节上限仍为五分钟，采集时长按已接收的 PCM 样本计数。替换预约支持
   满草稿、同一操作重试、取消、过期及重启恢复，普通追加仍限制 64 段，元数据
   最多临时增加一个替换条目。
2. 第 2 轮确认一项包含两个时序窗口的 P2 录音代次问题。旧编辑可能误取消新的
   录音，旧请求晚注册也可能取消并覆盖新任务。编辑事务现返回被退役的代次，
   取消仅匹配该代次，注册在替换活动任务前拒绝较旧或相同代次。
3. 第 3 轮独立检查修复后的完整项目，未确认新的可执行缺陷。设备宿主测试及
   数据、流、PCM、模型包的新鲜 race 检查均通过。
