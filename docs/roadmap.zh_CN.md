# 里程碑

以下实现里程碑均为计划。仓库初始化用于确立需求与验收条件。

| 里程碑 | 交付内容 | 验收条件 |
| --- | --- | --- |
| M1 中转与协议 | Go 服务、配置、mDNS、能力声明、有上限的设备接口 | 发现后可访问广播的服务，启动退出正常，数据结构与上限有明确文档 |
| M2 草稿与会话 | 持久化草稿段落、版本校验、分页会话索引、Hermes 会话映射 | 追加、删除、重连正常，迟到转写遵循段落生命周期，发送固定用户所见版本 |
| M3 OpenAI 转写 | 增量音频接收、上游实时会话、转写事件 | 代表性中文录音返回临时与最终文字，段落对应准确，背压有明确上限 |
| M4 Hermes 聊天 | 明确发送草稿、会话续接、过滤后的 SSE、消息恢复 | 一份审阅草稿对应一条逻辑消息，覆盖精确重试、长文字、分片媒体、错误和重连 |
| M5 AI Passport 客户端 | 发现、会话选择、录音、草稿审阅删除追加发送和回复显示 | 设备交互流程通过，实测空闲堆、最大连续块和栈余量支持录音联网并行 |
| M6 集成验证 | 重复完整交互与恢复测试 | 草稿或发送中重启、上游断线、慢网络、重复请求和长回复均有可观察结果 |

## 实现中需要确定的事项

- 设备音频编码、传输方式、采样率和缓冲上限。
- 草稿文字编辑粒度与实体按键映射。
- 设备接口路由、事件大小、文字窗口和会话分页大小。
- 音频与回复缓存保留策略。
- 待审批操作和不可显示媒体的呈现方式。
- 使用提供的凭据验证模型权限、延迟和识别准确性。

## 验证记录
